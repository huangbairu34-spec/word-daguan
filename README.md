# 单词大观 · 考研英语手机背诵手册

把考研核心词汇做成**手机端碎片化背诵**的单页应用：打开浏览器就能背，不需要装 App、不需要联网。

包含两套内容：

| 版本 | 词数 | 说明 |
| :--- | :---: | :--- |
| 英二 | 2,868 词 | 93 册单元，考研核心高频词 |
| 英一 | 同源数据 | 独立目录，见 `英一/` |

## 三种背诵模式

1. **🗂️ 卡片速记（Flashcard）** — 大字号英文 + 发音 + 考频热度，点击翻面看释义，左右滑动切词。
2. **📋 列表遮挡自测** — 一键模糊全页中文，逐词回忆，点击释义临时解除模糊。
3. **⭐ 生词本与全局检索** — 星标收藏、单独筛选难词，2,868 词毫秒级检索。

另外还有：

- **自动断点续背** — 记录章节、单词序号、模式与生词本状态，刷新后自动恢复
- **三套沉浸式主题** — 极简白 / 暗夜极客黑 / 护眼豆沙绿

## 手机访问

1. 双击 `启动手机访问.bat`（或 `python start_server.py`）；
2. 电脑会弹出带二维码的页面；
3. 手机连同一 Wi-Fi，用微信或相机扫码即可打开。

也可以在手机上直接打开 `index.html`，离线可用。
